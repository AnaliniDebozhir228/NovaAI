# NOVA

**NOVA** — экспериментальный персональный AI-ассистент для Windows на Python. Проект использует языковую модель через API Groq и умеет вызывать локальные инструменты компьютера.

> Проект находится в разработке. Сейчас это консольный прототип, а не готовое desktop-приложение.

## Возможности

- Общение с языковой моделью через Groq API.
- Получение текущих даты и времени.
- Открытие стандартного калькулятора Windows и Блокнота.
- Открытие сайтов в браузере с подтверждением пользователя.
- Сохранение истории диалога в локальную базу SQLite.

## Структура проекта

```text
NovaAI/

│   ├── __init__.py

└── .gitignore
```

## Требования

- Windows
- Python 3.10 или новее
- API-ключ Groq

## Установка и запуск

1. Склонируйте репозиторий:

   ```powershell
   git clone https://github.com/AnaliniDebozhir228/NovaAI.git
   cd NovaAI
   ```

2. Создайте виртуальное окружение:

   ```powershell
   py -m venv .venv
   ```

3. Установите зависимости:

   ```powershell
   .\.venv\Scripts\python.exe -m pip install openai python-dotenv
   ```

4. Создайте файл `.env` на основе `.env.example` и укажите свой API-ключ:

   ```env
   OPENAI_API_KEY=YOUR_GROQ_API_KEY
   OPENAI_MODEL=openai/gpt-oss-20b
   ```

   Не публикуйте `.env` и никому не отправляйте API-ключ.

5. Запустите NOVA:

   ```powershell
   .\.venv\Scripts\python.exe nova.py
   ```

## Используемые технологии

- **Python** — основа проекта.
- **Groq API** — доступ к языковой модели через OpenAI-совместимый клиент.
- **OpenAI Python SDK** — отправка запросов и обработка tool calls.
- **python-dotenv** — загрузка настроек из `.env`.
- **SQLite** — локальное хранение истории диалога.

## Безопасность

- Храните API-ключ только в локальном файле `.env`.
- Не добавляйте в Git файлы `.env`, базу данных, виртуальное окружение и личные данные.
- Перед открытием сайта NOVA запрашивает подтверждение.
- Проверяйте действия, которые ассистент предлагает выполнить на компьютере.

NOVA — учебный и экспериментальный проект. Архитектура и набор возможностей будут меняться по мере разработки.
